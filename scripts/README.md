# scripts/

项目脚本目录：环境初始化、构建、部署、开发辅助。

> Created: 2026-08-20
> Updated: 2026-08-20

## 目录结构

| 目录 | 用途 |
|---|---|
| [`setup/`](./setup/) | 环境初始化、依赖安装、配置生成 |
| [`build/`](./build/) | 构建辅助、产物检查 |
| [`deploy/`](./deploy/) | 部署、环境变量同步（平台待定） |
| [`dev/`](./dev/) | mock、调试、代码生成 |

## 脚本规范

- Shell 用 `.sh` 或 `.ps1`（本机默认 PowerShell，优先 `.ps1` 或注明调用方式）
- 其他运行时脚本用该语言惯用后缀（`.mjs`、`.ts`、`.py` 等，选定后再统一）
- 文件名 kebab-case
- 文件头注释：用途、参数、退出码
- 支持 `--help` 或在注释中写清用法
- 删除/覆盖类危险操作前必须确认
